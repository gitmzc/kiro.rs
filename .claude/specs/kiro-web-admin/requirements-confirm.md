# kiro-rs Web 管理系统需求确认

## 原始需求
为 kiro-rs 项目添加 Web 管理界面、请求统计系统和日志记录系统。

## 用户确认的需求细节

### 1. Dashboard 指标（完整版）
- **服务状态**: 运行时间、版本号、当前活跃凭据
- **凭据概览**: 总数、可用数、当前使用的凭据索引
- **今日统计**: 请求总数、成功数、失败数、错误率
- **Token 消耗**: 输入 Token、输出 Token、总消耗
- **响应时间**: 平均响应时间、P95 响应时间
- **每凭据使用量**: 各凭据的请求次数和 Token 消耗
- **24小时趋势图**: 请求量、Token 消耗的时间序列图表
- **实时请求流**: 最近的请求记录实时更新

### 2. 数据保留策略
- **统计数据**: 保留 7 天
- **日志数据**: 保留 7 天
- **自动清理**: 每日自动清理过期数据

### 3. 高级功能
- **深色模式**: 默认深色主题，支持切换
- **配置热重载**: 修改配置后无需重启服务
- **不需要**: 多语言支持

### 4. 页面模块

#### 4.1 Dashboard（仪表盘）
- 状态卡片：服务状态、凭据状态、今日请求、错误率
- Token 消耗卡片：输入/输出 Token 统计
- 24小时请求趋势图（折线图）
- 实时请求流（最近 20 条）

#### 4.2 凭据管理
- 凭据列表（优先级、状态、过期时间、失败次数）
- 上传凭据（拖拽上传 JSON 文件）
- 操作：启用/禁用、调整优先级、重置失败计数、删除
- 查看余额

#### 4.3 配置管理
- 显示当前配置（脱敏敏感信息）
- 支持热重载的配置项修改
- 保存并应用配置

#### 4.4 日志查看
- 实时日志流（SSE 推送）
- 日志级别过滤（INFO/WARN/ERROR）
- 关键字搜索
- 暂停/继续滚动

## 技术方案

### 前端
- **框架**: React 19 + Vite + TypeScript
- **UI**: shadcn/ui (Radix UI + Tailwind CSS)
- **图表**: Recharts
- **数据**: TanStack Query
- **嵌入**: rust-embed（编译进二进制）
- **主题**: 默认深色模式，支持切换

### 后端
- **框架**: 扩展现有 Axum Admin API
- **存储**: SQLite（统计数据持久化）
- **实时**: SSE（日志流推送，限流每秒最多 10 条）
- **日志**: tracing + tracing-appender（日志轮转）
- **认证**: 复用现有 admin_api_key（x-api-key / Bearer）

### 凭据状态定义
| 状态 | 颜色 | 说明 |
|------|------|------|
| Active | 绿色 | 正常可用 |
| Cooldown | 黄色 | 失败后冷却中 |
| RateLimited | 橙色 | 被限流 |
| Expired | 红色 | Token 已过期 |
| Disabled | 灰色 | 手动禁用 |

### SPA 路由支持
- rust-embed handler 实现 fallback
- 非静态文件请求返回 index.html
- 前端路由处理 /dashboard, /credentials 等

### 热重载边界
| 配置项 | 支持热重载 | 说明 |
|--------|-----------|------|
| thinking 预算 | ✅ | 运行时可修改 |
| 模型映射 | ✅ | 运行时可修改 |
| host/port | ❌ | 需要重启服务 |
| proxy 配置 | ❌ | 需要重启服务 |

### 新增 API 端点
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/admin/stats/summary` | 统计汇总 |
| GET | `/api/admin/stats/timeseries` | 时间序列数据 |
| GET | `/api/admin/stats/requests` | 最近请求列表 |
| GET | `/api/admin/logs/stream` | SSE 日志流 |
| GET | `/api/admin/config` | 获取配置 |
| POST | `/api/admin/config` | 更新配置（热重载） |
| GET | `/api/admin/health` | 健康检查 |
