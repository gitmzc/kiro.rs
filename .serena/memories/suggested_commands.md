# Suggested Commands

## Build & Run
- Build Release: `cargo build --release`
- Run: `./target/release/kiro-rs`
- Run with config: `./target/release/kiro-rs -c config.json --credentials credentials.json`
- Run via Cargo: `cargo run --release`

## Development
- Format: `cargo fmt`
- Lint: `cargo clippy`
- Test: `cargo test`

## Environment
- Log Level: `RUST_LOG=debug ./target/release/kiro-rs`
